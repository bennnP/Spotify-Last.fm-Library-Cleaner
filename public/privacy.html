Privacy policy

Last updated: September 13, 2026

Spotify Library Cleanup is a local web tool for reviewing tracks that have not been played recently. This policy explains what the application handles when you run it.

Data the app handles

  • Spotify access and refresh tokens are held in server memory to call Spotify on your behalf.
  • A Last.fm username and the listening history returned by Last.fm are used to match tracks when you choose that source.
  • Spotify history ZIP uploads are processed in memory and are not intentionally written to disk.
  • Analysis results and selected tracks are held in memory while the server is running.

What is not promised

This project does not yet provide a persistent database, account system, multi-user isolation, audit log, or hosted data-retention controls. Run it locally, keep your environment variables private, and do not expose the development server directly to the public internet.

Third parties

When you use the tool, requests may be sent to Spotify and, if selected, Last.fm. Their own privacy policies and terms govern those services. The application does not sell personal data.

Contact and changes

For a deployed version, replace this page with the operator's legal contact details and a policy reviewed for the deployment jurisdiction. This policy changes when the application's storage or sharing behavior changes.
